## ChartNav — provider-reviewed clinical workflow for ophthalmology.

### Problem

Ophthalmology charting drifts. Retinal findings live in narrative
text. OD/OS diagrams are paper or one-off. Pre-visit chart prep is
manual.

### Solution

ChartNav is an ophthalmology-specific clinical workflow assistant.
Provider-reviewed at every step.

### Top 5 features

1. AI scribe session lifecycle — draft → review → finalize.
2. Findings-to-retinal-diagram proposal review — read-only
   suggestions; provider applies.
3. OD/OS retinal drawing canvas — versioned + signed; signed
   artifacts immutable; edits fork explicitly.
4. Patient-friendly summary draft — provider-reviewed, never sent
   to a patient automatically.
5. Pre-visit clinical brief + provider action review queue —
   review tasks only.

### Safety posture

- ChartNav surfaces structured chart context. The provider decides.
- Audit metadata-only by code-and-test contract.
- Cross-organization access returns `404 patient_not_found`.
- **What ChartNav is not:** not a certified EHR replacement; not
  autonomous diagnosis; not automatic orders / coding / referrals /
  patient messaging; not real-PHI production without legal /
  security review.
