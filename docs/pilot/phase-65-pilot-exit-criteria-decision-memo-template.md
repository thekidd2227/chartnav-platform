# Phase 65 Pilot Exit Criteria and Decision Memo Template

Status: template
Audience: business owner, pilot owner, practice decision maker

Complete this in a practice-approved private location at the end of a
pilot. Do not store real PHI in this repo.

## Header

```text
Practice:
Pilot dates:
Pilot scope:
Named workflows:
Decision meeting date:
Practice decision maker:
Practice clinical champion:
ChartNav pilot owner:
Recommendation:
```

## Decision Options

Choose one:

- Continue same scope.
- Continue with narrower scope.
- Expand after new security/scope review.
- Pause for repair.
- Stop.

## Required Inputs

- [ ] Gate 3 approval was complete before any real-PHI session.
- [ ] Pilot scope did not expand without review.
- [ ] Issue log reviewed.
- [ ] Success metric tracker reviewed.
- [ ] S1/S2 issues resolved or named as blockers.
- [ ] Practice feedback captured.
- [ ] Security/compliance owner has no unresolved blocking concern.
- [ ] No unsupported public claims will be made from pilot results.

## Safety Review

- S1 count:
- S2 count:
- Sensitive-content logging concern? yes/no
- Cross-org or wrong-role concern? yes/no
- Production LLM or unapproved vendor concern? yes/no
- Demo/real-PHI boundary concern? yes/no

If any answer is yes, document the resolution or recommend pause/stop.

## Expansion Gate

Expansion requires a new review if any of these change:

- New workflow surface.
- New user role.
- New location.
- New vendor.
- New integration.
- New hosting/logging/backup configuration.
- Any real-PHI data flow change.
