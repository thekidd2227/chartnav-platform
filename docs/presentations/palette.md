# ChartNav Presentation Palette

> The branded palette used by every ChartNav presentation
> generated by the Phase 17D system. Pulled from the live
> product CSS at `apps/web/src/styles.css` so the slides match
> the landing page and the in-product UI.

When the product CSS palette changes, sync `tools/presentations/theme.js`
in the same PR. Do not invent new hex values for slides; pick
from this palette.

---

## Color rules

1. **Slides default to a white surface** with a teal accent bar at the top — never a fully colored background.
2. **One primary color per slide** — teal carries identity; pulse red is reserved for the negative ("does not do") column and the logo cross.
3. **No gradients.** The product UI doesn't use them; the decks should match.
4. **Never use red on safe-claims contract text.** Red signals the boundary line ("does not"), not the rule ("provider-reviewed workflow support").
5. **Card outlines** prefer `Line` (`#DCE5EA`) over a heavier border. Strong borders compete with the title rule.
